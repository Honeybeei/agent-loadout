# Writing Style

Documents follow the Framework writing rules. Read [Writing rules](../../../dev-framework/project/knowledge/dev-framework/writing-rules.md) before judging or proposing a fix.

## Script findings

| Finding | Usual fix |
| --- | --- |
| Hard-wrapped prose | Join each paragraph or list item onto one line, and keep the structural line breaks |

## Judgment checks

Unit: one document.

| Check | Rule |
| --- | --- |
| Explanatory prose is in English; other languages appear only in literal content whose exact form is needed | [Language](../../../dev-framework/project/knowledge/dev-framework/writing-rules.md#language) |
| Sentences are concise and clear, and keep their conditions, exceptions, and rationale | [Documentation style](../../../dev-framework/project/knowledge/dev-framework/writing-rules.md#documentation-style) |
| Enumerations use lists; relationships use tables, graphs, or trees; directory trees use box-drawing characters | [Documentation style](../../../dev-framework/project/knowledge/dev-framework/writing-rules.md#documentation-style) |
| A Knowledge document above about 150 lines would be clearer compressed or split | [Length](../../../dev-framework/project/knowledge/dev-framework/knowledge-documentation.md#length) |
