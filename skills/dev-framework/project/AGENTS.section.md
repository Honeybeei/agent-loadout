## Dev Framework

This project follows the Dev Framework. Before working:

1. For work inside a workspace, find the affected workspaces in `dev.yaml` and read each workspace's `README.md`.
2. Read [Dev Framework rules](knowledge/dev-framework.md) and the rules it lists for your task.
3. Follow the project's Knowledge index, `knowledge/README.md`, to the documents your task needs, using the reading conditions it states.

The user plans and builds with the skills in `.agents/skills/`, in the sessions [Development workflow](knowledge/dev-framework/workflow.md) defines: the lead session at the main checkout plans, explores, and builds collaborative work, and an implementation session in its own worktree builds one blackbox leaf. Start `dev-plan`, `dev-explore`, `dev-collaborate`, `dev-blackbox-dispatch`, `dev-blackbox-implement`, and `dev-blackbox-review` only when the user invokes them; use `dev-next` when the user asks where things stand or what to do next.

This section and the other Framework-managed material listed in [Project structure](knowledge/dev-framework/project-structure.md#framework-managed-material) are managed copies of the Framework and are replaced when the project is updated to a newer Framework. Keep them unedited; put project-specific rules outside this section.
