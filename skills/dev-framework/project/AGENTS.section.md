## Dev Framework

This project follows the Dev Framework. Before working:

1. For work inside a workspace, find the affected workspaces in `dev.yaml` and read each workspace's `README.md`.
2. Read [Dev Framework rules](knowledge/dev-framework.md) and the rules it lists for your task.
3. Follow the project Knowledge indexes to the documents your task needs, using the reading conditions they state.

This section, `knowledge/dev-framework.md`, and `knowledge/dev-framework/` are managed copies of the Framework and are replaced when the project is updated to a newer Framework. Keep them unedited; put project-specific rules outside this section.
